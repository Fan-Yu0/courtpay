Internet Court GenLayer x402

Payments that can be
appealed.

x402 settles before the buyer reads the artifact. CourtPay turns the signed receipt into a case: GenLayer validators fetch the delivery themselves and decide whether the seller kept the promise — the verdict releases the refund.

Watch the 45s demo Source on GitHub

Pay

Seller answers 402 Payment Required; the buyer signs a real EIP-3009 authorization and gets a seller-signed receipt.

Dispute

The receipt becomes a case on a GenLayer contract with the public delivery URL and the promise it was sold under.

Judge

Every validator fetches the artifact and re-runs the same review. Verdict bands must match exactly; refund is a pure function of the verdict.

Reproduce it

git clone https://github.com/Fan-Yu0/courtpay
cd courtpay
python -m venv .venv && .venv\Scripts\activate
pip install -r requirements.txt
python -m courtpay demo --fresh
CourtPay is an open demonstration built for the GenLayer × Internet Court Builder mission. Settlement in the demo is a local ledger; the eip-3009 payload is real. MIT licensed.
